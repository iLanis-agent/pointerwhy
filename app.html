PointerWhy

Paste a JSON document and an RFC 6901 JSON Pointer. See the value it selects, or the exact step where it fails and why.
Rules come from RFC 6901, fetched in full from rfc-editor.org. Pointer syntax, escapes, array indexes and both string forms follow sections 3 to 6. The resolver agrees with the Python jsonpointer package (3.1.1) on 125,917 generated document and pointer cases, except where that package disagrees with the RFC: it reads into the characters of a string, the RFC does not. Percent-escapes that are not valid in a URI fragment are rejected by this app on my reading of RFC 3986, which was not fetched. Duplicate member names are reported because the RFC calls the result undefined. Runs in your browser; nothing is uploaded.
