What it does

  • Resolves a JSON Pointer against your document and shows every step, or the step that fails and why.
  • Catches the usual mistakes: unescaped slash or tilde in a key, leading zeros and "-" in array indexes, JSONPath syntax, a URI fragment pasted as a string, bad percent-escapes, duplicate keys.
  • Shows the same pointer in both RFC forms, and lists every valid pointer in the document.

How far to trust it

  • Follows RFC 6901 (fetched in full). On 125,917 generated cases it agrees with the Python jsonpointer package, which differs from the RFC in one place: it reads into the characters of a string. Percent-escape strictness follows my reading of RFC 3986, which I did not fetch.
